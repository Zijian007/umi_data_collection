# AprilGrid 标定板

当前标定流程使用 **6×6 AprilGrid、tag36h11、2 格黑边**。每个标签由 6×6 数据格和四周各 2 格黑边组成，外黑框共 10×10 格。普通 1 格黑边标签和旧版 v1 打印板不兼容；打印前确认 PDF 页脚为 `v2 border=2`。

## 文件与参数

- [`aprilgrid.json`](aprilgrid.json)：唯一的板布局定义，包含标签族、黑边、行列数和间距比例，不包含纸张或标签的物理尺寸。当前检测器仅支持其中的 tag36h11 和 2 格黑边。
- [`prints/`](prints/)：可打印 PDF、用于预览/检测的 PNG，以及对应的 `*_meta.json` 生成与自检记录。元数据描述打印资产，不作为求解参数。
- `--tag-size-mm`：本次使用的板上，**实测单个标签外黑框的边长**，单位 mm；包含黑边、不包含外侧白边。程序将其换算为米，与布局合并后生成求解器所需的 `run/work/aprilgrid.json`，并记录在本次运行输入中。
- [`config/calibration.yaml`](../../config/calibration.yaml)：检测、PnP、覆盖评估和验收参数。它不定义打印尺寸。

无需编辑 JSON/YAML 来选择 A4 或 A3；本目录不再维护 Kalibr YAML 和各纸张的重复板配置。需要给外部工具使用时，按该工具的格式从布局和实测尺寸生成。

## 打印与测量

| 纸张 | 打印文件 | 标签外黑框边长（标称） | 标签间白色间隔 | 阵列外框 | 建议拍摄距离 |
|---|---|---:|---:|---:|---:|
| A4 | [A4_24mm.pdf](prints/A4_24mm.pdf) | 24 mm | 7.2 mm | 180×180 mm | 0.3–0.5 m |
| A3 | [A3_36mm.pdf](prints/A3_36mm.pdf) | 36 mm | 10.8 mm | 270×270 mm | 0.4–0.7 m |

`tagSpacing = 0.3` 表示白色间隔为标签外黑框边长的 0.3 倍；标签中心间距为边长的 1.3 倍。标签 ID 从左下角 0 开始，向右递增，再向上逐行递增至 35。

1. 以 **100% 实际尺寸**打印 PDF，关闭“适合页面”和自动缩放；使用哑光纸，不覆亮膜。
2. 量标签外黑框边长，并核对 PDF 底部的 100 mm 标尺。边长与标称值相差 0.3 mm 以内仍应填写实测值；差得更多应重新打印。检查横向、纵向尺寸一致，不能靠一个边长参数修正非均匀缩放。
3. 贴在平整硬板上，保持无弯曲、褶皱，保留白边。
4. 固定标定板，均匀照明，避免反光和遮挡；录制时移动相机，板保持不动。

例如，A4 板实测外黑框边长为 23.9 mm：

```bash
./umi-calib run <标定录像目录> --tag-size-mm 23.9
```

`--tag-size-mm` 默认 24.0；使用 A3 板必须显式填写实测值，不能沿用默认值。`./umi-calib check` 检查打印记录的标签编码、黑边、行列和间距是否符合统一布局，以及 PDF/PNG 文件是否存在；实物尺寸和平整度仍需人工检查。

标定 C 段的 ORB 辅助初始化也自动使用这个实测尺寸，无需另改 `trajectory.yaml`。日常场景建图或独立轨迹不经过这一步派生，若使用标签辅助初始化，仍须设置实际使用的 `orb.initial_tag_size_m`。

A/B/C/D 的完整录制方法见 [标定指南](../../docs/标定.md)。

## 环境镜头的 ArUco 海报

[用户提供的 PDF](../UMI_ArU..an.pdf) 与 [environment_poster.json](environment_poster.json) 用于环境观测，不替代上面的 AprilGrid 相机标定板。字典为 `DICT_4X4_100`、黑边 1 格；7 列 × 11 行，ID 从左到右、从上到下为 12–88，标签朝向一致。PDF 纸张为 1000 × 1500 mm，黑色外框边长 100 mm、中心间距 130 mm；左/右页边距为 60 mm，上/下为 50 mm。

布局保存每个 ID 的四个米制角点。原点是纸张左上角，X 向右、Y 向下、Z 指入纸面；角点顺序与 OpenCV 解码后的 TL/TR/BR/BL 一致。来源 PDF 的 SHA256 写入布局。已核对全部 77 个 PDF 矢量外框，并将 PDF 渲染后逐个解码验证 ID、位置和朝向。

当前 `geometry_status: pdf_design` 仅确认设计尺寸；打印时使用 100% 实际尺寸，并实测黑框边长及横纵跨标签距离。打印非等比缩放、折皱或单个标签重新粘贴会使旧几何失效。海报整体可在不同录像之间移动，各段位姿重新求解；同一段录像内保持静止、平整。

独立检测入口见[视觉模块说明](../../software/vision/README.md)。
