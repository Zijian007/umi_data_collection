# 查看器代码阅读指南

运行和操作见 [三维查看指南](../../docs/查看.md)，数据格式见 [轨迹结果](../../docs/轨迹/结果.md)。

## 阅读顺序

`server.main()` 创建 `RecordingCatalog` 并启动 HTTP 服务；`data.py` 通过轨迹模块的统一入口读取结果、视频和摘要。浏览器的 `app.mjs` 管理选择与播放状态，三维、视频、曲线共用轨迹时间轴。

## 文件职责

```text
software/viewer/
  data.py            结果发现、TUM / CSV 读取和时间对齐
  server.py          HTTP API、本地静态资源与视频 Range 流
  media.py           兼容模式的限并发 FFmpeg 解码
  cache.py           查看器磁盘缓存、文件身份、跨进程锁与原子发布
  maps.py            地图校验、旧图集按需转换与缓存
  static/
    app.mjs          录像选择与统一播放状态
    scene.mjs        三维点云、关键帧、轨迹和姿态轴、鼠标操作
    chart.mjs        速度曲线与点击定位
    media.mjs        兼容画面请求合并、解码及与位姿同步
    math.mjs         时间定位与四元数运算
    viewer.css       自适应布局
```

浏览器侧自行计算三维透视投影，Canvas 显示轨迹；不从 CDN 加载绘图库。大轨迹只在绘制轮廓时降采样，逐帧读取和时间定位保留原始索引。对录像目录外的软链接不暴露文件内容，视频支持 HEAD 和单段 HTTP Range，便于拖动跳转。

测试与依赖环境见 [代码维护](../../docs/dev/README.md#验证)。Node 仅用于前端测试。

## 地图读取

共享场景任务由 `episodes.py` 适配：只读当前 `results` 指针、校验两只手的场景版本/坐标身份，裁出共同时间区间，再对另一只手的位置和四元数插值。浏览器的 `paired.mjs` 跟随主时间同步第二路视频；两路各自使用 `video_time_offset_s`，不把共同区间起点误当成视频起点。此读取路径仍只依赖 Python 标准库。

`GET /api/recordings/<id>/map` 独立加载前镜头地图，不阻塞轨迹与视频。优先读取 `details/map.json`；旧结果从摘要选中轮次的 `.osa` 转换。转换结果在查看器缓存目录持久保存，内存保留最近 4 份；服务重启后不必再次加载 ORB 词典。输入地图、选中轮次、轨迹、定位文件或转换代码/引擎发生变化时使用新缓存身份，不写回录像目录。真正转换时串行加载词典，读取其他已有磁盘缓存不排队。

`software/trajectory/map_data.py` 用独立的 `umi_export_atlas` 读取图集，再将逐帧定位与最终相机轨迹拟合为 Sim(3) 展示变换。退化或残差过大时保留原始地图坐标，浏览器隐藏轨迹叠加并更换单位提示；不合并不同子地图。

每张子地图最多展示 50000 点，关键帧保留时间、位置和姿态，原始 `.osa` 不改变。展示拟合不修改融合算法，残差不能解释为真实轨迹精度。后镜头地图暂不展示。

## 视频加载与缓存

首次显示通过版本化 poster URL 读取缓存首帧。已有 WebM 预览时，轨迹 API 直接返回其地址，浏览器不再先读取大 MP4。没有预览时先显示原视频或兼容画面；支持 VP8 的浏览器通过 `/preview` 启动后台生成，准备好后保持当前时间和播放状态切换。用户主动选择兼容模式时不自动切走；录像切换取消旧轮询，旧响应不能覆盖新画面。

预览只读原视频，最大 720 像素宽、不放大小图，保持帧率和视野，约 1.5 Mbps，关键帧间隔 30 帧。最多一份编码任务运行、一份排队；生成失败保留原视频/兼容播放。首帧缓存到磁盘，最近 64 张兼容 JPEG 在内存复用，不生成整段抽帧目录。WebM 支持 Range 与版本化不可变 URL；原视频支持 ETag 重新验证。

缓存默认在 `$XDG_CACHE_HOME/umi-view`（通常为 `~/.cache/umi-view`），`UMI_VIEW_CACHE` 可指定其他目录。`maps/`、`previews/`、`posters/` 都是可再生数据，与录像目录隔离。大文件以路径、尺寸、mtime、ctime、inode 识别变更，预览编码选项及 FFmpeg 身份也进入缓存键；跨进程文件锁防重复生成，原子发布避免读取半成品。缓存可以清理，之后按需重建；不自动删除用户录像或轨迹。

默认扫描 `scenes/`，场景任务以“场景/批次/任务”显示。采集批次位于 `sessions/<批次>/`；自动扫描跳过 `archive/` 历史归档，直接指定归档目录仍可查看独立结果。
