# 海报后端地图融合交接（2026-11-27）

两种海报后端都已接入工作镜头 ORB 地图，使用实测 KB4 标定。开关 `poster.front_map_pixel_fusion` 默认关闭。`poster_independent` 按每帧像素匹配的可信度加权地图位姿。`poster_vio` 联合估计每张子图的尺度和放置，只有位置、朝向、尺度和位姿残差通过检查的地图观测才能填补位置支持缺口。增强解验收失败时，用同一批冻结观测重算基础 VIO，沿用原有质量门限。[实现与配置说明](../03-场景处理.md#海报后端的工作镜头地图像素权重)

## 运行与查结果

在仓库根目录运行。单独验证某个后端时，将批次 `collection.yaml` 的 `backend.mode` 设为 `poster_independent` 或 `poster_vio`。

```bash
./umi-scene run scenes/test_shelf2 --force --expert-config docs/examples/poster_front_map_pixels.yaml
```

查看 `take_*/results/data/episode.json` 的 `scene.reconstruction_backend`。对启用地图且生成了子图的 VIO 任务，`scene.front_map_selection.selected` 为 `with_front_maps` 表示发布增强解，为 `without_front_maps` 表示发布基础解。回退原因在同一对象的 `rejected_reason`；被拒解的逐手证据在对应运行目录的 `poster_vio/front_map_attempt.json`。
