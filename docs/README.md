# 文档导航

第一次使用从[安装与日常使用](安装与日常使用.md)开始，按 **准备设备 → 手写配置 → 放视频 → run → 查看和验收 → 导出** 完成一次采集。之后按具体问题查阅参考文档。

## 操作指南

| 要完成的事 | 阅读入口 |
|---|---|
| 安装环境并完成一次采集 | [安装与日常使用](安装与日常使用.md) |
| 录制 A/B/C/D、求解并登记相机标定 | [相机与夹爪标定](标定.md) |
| 选择实测/工厂内参并切换配套标定 | [标定来源](标定.md#选择实测或工厂内参) · [套件来源配置](../kits/README.md#前后镜头独立选择来源) |
| 调整场景、选择单手、补片、复用地图或排障 | [场景配置与排障](场景处理.md) |
| 查看结果、人工验收、导出普通成果 | [结果查看与验收](结果查看与验收.md) |
| 填写指令、核验同步、接入宽度、导出训练包 | [训练数据准备与导出](训练数据.md) |

| 需要核对的内容 | 唯一详细定义 |

项目使用 `umi-calib` 管设备标定、`umi-scene` 处理场景轨迹、`umi-view` 查看结果。现行操作以这些指南为准；终端可用 `umi-view --help`、`umi-scene <子命令> --help`、`umi-calib <子命令> --help` 查阅参数。
