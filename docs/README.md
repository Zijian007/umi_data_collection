# 文档导航

用户只需要记住一条主线：标定设备 → 配置套件 → 准备批次 → 建图和抽取 → 查看、验收、导出。

| 目的 | 文档 |

| 安装、标定后的日常操作、任务录像 | [安装与日常使用](安装与日常使用.md) |
| 套件、批次、地图、任务和高级处理 | [场景处理](场景处理.md) |
| 设备资产、目录、TCP 和坐标系 | [设备与坐标](设备与坐标.md) |
| 相机和夹爪标定 | [标定](标定.md) |
| 查看器、结果字段、人工验收和导出 | [结果查看与验收](结果查看与验收.md) |
| 共享场景与独立轨迹算法 | [算法原理](算法原理.md) |
| 训练指令、同步、宽度标定和训练包 | [训练数据](训练数据.md) |
| 参数配置 | [统一参数配置](../config/README.md) |
| 代码维护与历史记录 | [代码维护](dev/README.md) · [来源与变更历史](dev/PROVENANCE.md) |

项目入口：`umi-calib` 管设备标定，`umi-scene` 处理场景轨迹，`umi-view` 查看结果。模块阅读指南位于对应 `software/` 目录。
