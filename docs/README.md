# 文档导航

第一次阅读先看[业务心智模型](业务心智模型.md)，再按[安装与日常使用](安装与日常使用.md)完成一次采集。当前用户流程是 **准备设备 → 手写 kit/collection → 放视频 → run → 查看和验收 → 导出**。

文档分成四层：业务总览、日常操作、字段/算法参考、开发与历史档案。日常运行只需要前三层；`docs/dev/` 中的变更记录和历史实验不作为当前操作步骤。

## 操作指南

| 要完成的事 | 阅读入口 |
|---|---|
| 安装环境并完成一次采集 | [安装与日常使用](安装与日常使用.md) |
| 录制 A/B/C/D、求解并登记相机标定 | [相机与夹爪标定](标定.md) |
| 整理 SDK 卡中的 INSV 原片并交接给 UMI | [INSV Organizer 使用教程](../../insv_organizer/docs/使用教程.md) · [业务心智模型](业务心智模型.md#organizer-交接边界) |
| 选择实测/工厂内参并切换配套标定 | [标定来源](标定.md#选择实测或工厂内参) · [套件来源配置](../kits/README.md#前后镜头独立选择来源) |
| 调整场景、选择单手、补片、复用地图或排障 | [场景配置与排障](场景处理.md) |
| 查看结果、人工验收、导出普通成果 | [结果查看与验收](结果查看与验收.md) |
| 填写指令、核验同步、接入宽度、导出训练包 | [训练数据准备与导出](训练数据.md) |
