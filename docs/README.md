| 要做什么 | 阅读入口 |

| 整理原始 INSV，或从 Organizer 交接 | [日常使用的批次准备](安装与日常使用.md#4-准备本次配置和视频) · [Organizer 交接](安装与日常使用.md#organizer-交接边界) |

| 对照视频与轨迹，人工验收，导出成果 | [结果查看与验收](结果查看与验收.md) |
| 填写指令、核验同步、接入宽度并导出训练包 | [训练数据](训练数据.md) |
