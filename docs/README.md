# 文档导航

## 使用教程

1. 安装环境并了解一次采集的完整流程。 [01 安装与日常使用](01-安装与日常使用.md)
2. 录制 A/B/C/D 四段、求解并登记相机参数，配置夹爪测量。 [02 相机与夹爪标定](02-相机与夹爪标定.md)
3. 整理原片、配置批次与后端，运行场景处理并排障。 [03 场景处理](03-场景处理.md)
4. 对照视频、轨迹和结果报告。 [04 结果查看](04-结果查看.md)
5. 填写指令、核验同步和接入夹爪测量。 [05 任务同步与夹爪测量](05-任务同步与夹爪测量.md)

已有标定和套件时，可直接开始准备本次批次与原片。 [准备批次和视频](01-安装与日常使用.md#4-准备本次配置和视频) · [Organizer 交接](01-安装与日常使用.md#organizer-交接边界)
