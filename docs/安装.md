# 安装与环境检查

[文档导航](README.md) · [下一步：标定相机](标定/说明.md)

## 机器要求

| 项目 | 要求 |
|---|---|
| 平台 | 推荐 Linux x86_64；既有安装记录覆盖 Ubuntu 20.04 / 22.04。自带 Basalt 标定程序仅支持 Linux x86_64 |
| CPU / 内存 | 建议至少 4 核、8 GB；不需要 GPU |
| 磁盘 | 轨迹环境约 5 GB，标定组件额外约 400 MB；标定过程中还需约 10–20 GB 临时空间，另留录像与结果空间 |
| 网络 | 安装需访问 GitHub、conda.anaconda.org、pypi.org；处理录像时离线运行 |
| 系统工具 | `bash`、`curl`、`tar`；安装器将项目依赖放在 `.deps/`，已有这些系统工具时无需 sudo |

轨迹安装器另有 aarch64 分支，但未按 x86_64 同等验证；该分支也不提供自带 Basalt。Windows 用户推荐在 WSL2（Ubuntu 22.04）中运行。

## 本机安装

```bash
git clone https://github.com/Zijian007/umi_data_collection.git
cd umi_data_collection
bash install.sh
./umi-traj check
```

安装器下载 micromamba，按锁定清单安装 Python、FFmpeg、OpenCV 和编译器，安装 GTSAM，再编译 Pangolin 与 ORB-SLAM3。首次安装通常约 15–40 分钟，取决于下载速度与机器性能。中断后可以重跑，已完成的步骤会跳过。

首次执行 `./umi-calib` 会补装标定组件；也可以提前安装并检查：

```bash
bash software/calibration/setup/install.sh
./umi-calib check
```

标定安装器解压仓库内的 Basalt 预编译包，并创建 `.deps/calib_env/`；不需要再编译 Basalt。环境检查终端以 `[完成] 环境检查通过` 收尾。

## 安装位置与日志

默认日志在 `.deps/logs/`。安装失败时先看终端给出的日志；网络恢复后直接重跑安装命令。

```bash
# 自定义依赖目录；以后运行工具也要使用同一个 UMI_DEPS
UMI_DEPS=/data/umi-deps bash install.sh
UMI_DEPS=/data/umi-deps ./umi-traj check
UMI_DEPS=/data/umi-deps ./umi-calib check
```

`JOBS=8 bash install.sh` 可限制编译并行数。默认按本机 CPU 编译，换到其他机器应重新安装。删除依赖目录可卸载环境，录像、标定批次结果与 `registry/` 分别存放。

## Windows (WSL2) 运行说明

对于 Windows 机器（如 Intel i7/i9 或 AMD Ryzen），推荐使用 Windows Subsystem for Linux 2 (WSL2)：
1. 安装并进入 Ubuntu 22.04：`wsl --install -d Ubuntu-22.04`；
2. 建议分配至少 8 GB 内存；
3. 进入 WSL2 终端后按照上方【本机安装】标准流程执行 `bash install.sh` 即可。

## 常见安装问题

| 问题 | 检查方式 |
|---|---|
| 提示尚未安装 | 确认 `.deps/env.sh` 存在，或运行时指定正确的 `UMI_DEPS` |
| 下载失败 | 核对网络或代理，查看 `.deps/logs/` 后重跑安装 |
| 标定组件缺失 | 运行标定安装器，再执行 `./umi-calib check` |
| 迁移环境后引擎无法运行 | 在目标机器重新安装，避免复用按另一台 CPU 编译的依赖目录 |

安装后按 [设备与目录](设备与目录.md) 放置录像，再开始 [相机标定](标定/说明.md)。
