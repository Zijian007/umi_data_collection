这里展示本轮建图原片的放置位置。实际采集时，在真实场景的 `<批次>/mapping/` 下放本轮原始 `.insv`，保留相机原名。

然后在真实批次的 batch.yaml 填写套件，运行 `./umi-scene run <批次目录>`。文件直接引用，来源与相机测量在本批次清单固定；地图产物另存到本批次的 `.umi/maps/versions/`，生成后将版本固定到本批次。

“一段建图录像＋随后几次操作”是一个批次；再次录制建图视频时新建下一个批次。每个 take 继承本批次的地图，不会随另一批次的新地图变化。

本 `example_scene` 只用于展示，不能直接作为真实采集使用。
