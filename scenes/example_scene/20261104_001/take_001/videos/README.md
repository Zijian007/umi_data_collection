这次操作的原片按手放置，保留原始文件名：

```text
videos/
├── left/原始文件名.insv
└── right/原始文件名.insv
```

单手只放对应侧；一次操作放在一个 take 中，每侧一段，多次操作分成 `take_001/`、`take_002/` 等目录。执行 `./umi-scene run <批次目录>` 后，程序按套件和录像内部序列号确认左右，保存本 take 的录制清单，直接引用这里的原片。

尚未分好任务的原片也可放在批次的 `pending/left/`、`right/`，程序配对成功后将其归入对应 take，清单保存成功后清除暂存副本。歧义不会强行配对。

本目录是示例说明，实际使用时请建立自己的场景和批次。
